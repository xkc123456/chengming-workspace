# 澄明 · 市场研究项目工作台

面向完整市场研究项目的全栈协作工具，覆盖方向评分与智能评估、成员容量和任务分配、CSV 摘要与 SPSS 分析建议、商业写作、展示故事板、答辩顾问及项目档案导出。

## 运行

- `npm install`：安装依赖
- 参考 `.env.example` 配置本地环境变量
- `npm run dev`：开发服务（端口 3000）
- `npm run check`：TypeScript 检查
- `npm run db:push`：同步数据库结构
- `npm run build && npm start`：生产构建与启动

使用 Kimi 登录；项目内容持久化在云端数据库。智能功能通过服务端模型接口调用，凭证不会发送到浏览器。CSV 仅在浏览器本地解析字段和摘要，原始文件不会上传。
